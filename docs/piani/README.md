# docs/piani — Piani di lavoro per-feature (effimeri)

Qui vivono i `PIANO_<feature>.md` dei lavori che durano più di una sessione.
Sono **git-ignorati** di proposito (`.gitignore`: `docs/piani/*.md`): non sono
documentazione viva, sono la mappa operativa di un lavoro in corso.

- **Formato e regole:** `WORKFLOW.md` (root), §2.
- **Uno per feature**, non un file unico: i lavori su ONEFLUX vanno in parallelo.
- **Ciclo di vita:** si crea all'apertura di un lavoro lungo, si aggiorna a ogni
  fase, **si elimina a feature deployata** — l'esito va nella memoria
  persistente (`memory/project_*.md`), non qui. Precedente: i piani della
  ripartizione costi catena, eliminati il 17/7/2026 dopo il deploy (vedi
  `docs/storico/README.md`).

Solo questo README è tracciato in git; i piani veri no.
